## FlopText RGB 1.9.0: Polished Editor

### New
- Added a build for **Minecraft 26.2**.

### Improved
- Redesigned the gradient slider: stops are now thin markers with a color knob under the bar, so the gradient is never covered.
- The selected stop is larger with an accent ring and shows its position in percent.
- Stops highlight when hovered, and have a larger click area.
- The gradient bar is framed and uses its full height with a subtle highlight and shade.
- The preview box has a border and the selected-color swatch has an even frame.

### Notes
- Available for Minecraft 26.1.2, 26.2 and 26.3. **26.2 is new and still being tested.**
- Source code is now public: https://github.com/MattThatsWho/FlopText-RGB
- Requires Fabric API and Cloth Config. Mod Menu is recommended.

## FlopText RGB 1.9.0: Polished Editor

### New
- Added a build for **Minecraft 26.2**.

### Improved
- Redesigned the gradient slider: stops are now thin markers with a color knob under the bar, so the gradient is never covered. The selected stop is larger, shows its position in percent, and stops highlight on hover.
- One consistent look on every screen: a single flat button style (confirm actions blue, destructive actions red, disabled buttons dimmed). Community Presets and Settings now use the same colors as the editor and Library.
- The [B] [I] [S] [U] buttons light up when a style is on.
- Cleaner layout: title centered over the editor, preview text centered in its box, gradient bar lined up with the text fields, and button rows aligned with even spacing.
- Very dark gradients (like Netherite) get a light backdrop in previews and preset cards so they stay readable.
- The gradient bar and preview box now have clean frames.

### Notes
- Available for Minecraft 26.1.2, 26.2 and 26.3. **26.2 is new and still being tested.**
- Source code is now public: https://github.com/MattThatsWho/FlopText-RGB
- Requires Fabric API and Cloth Config. Mod Menu is recommended.

### A Cleaner, More Consistent FlopText RGB

**Polished Editor** gives FlopText RGB a full visual pass. The gradient slider has been redesigned, and every screen now shares the same look, so the whole mod feels like one tool.

### What's New?

- **New Stop Markers:** Each stop is now a thin marker with a color knob underneath the bar, instead of a square sitting on top of your gradient. You can see every color change clearly.
- **Selected Stop Highlight:** The stop you're editing is larger with an accent ring, and it shows its exact position in percent. Stops also light up when hovered and have a bigger click area.
- **One Button Style Everywhere:** The editor, Library, folders, Save Preset, Community Presets and Settings now share one flat button style. Confirm actions are blue, destructive ones are red, and disabled buttons are dimmed.
- **Style Toggles You Can See:** The **[B] [I] [S] [U]** buttons now light up when a style is on.
- **Better Alignment:** The title is centered over the editor, preview text is centered in its box, and the gradient bar lines up with the text fields. Button rows now end on the same edge.
- **Dark Gradients Stay Readable:** Very dark presets, like Netherite, get a light backdrop in previews and preset cards instead of disappearing into the dark background.
- **Matching Colors:** Community Presets and Settings use the same neutral colors as the editor and Library.

### Now on Minecraft 26.2 Too

FlopText RGB now has a build for **Minecraft 26.2**, alongside 26.1.2 and 26.3.

### Open Source

The source code is now public on GitHub! Take a look, fork it, or build on it.
